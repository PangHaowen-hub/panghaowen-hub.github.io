# Haowen Pang

Personal academic homepage for Haowen Pang, built with React, Vite, and Tailwind CSS.

## GoatCounter

This site is configured to use the GoatCounter code `panghaowen-hub`.

Create a GoatCounter site with that code, then build and deploy as usual.
To change the code later, edit `.env.production`:

```sh
VITE_GOATCOUNTER_CODE=panghaowen-hub
```

The app loads GoatCounter only when `VITE_GOATCOUNTER_CODE` is set. If you use a
custom GoatCounter endpoint, set `VITE_GOATCOUNTER_ENDPOINT` to the full
`https://<code>.goatcounter.com/count` URL instead.
